# Инструкция по работе с пайплайном индексации

Этот документ описывает архитектуру и порядок работы с локальным пайплайном индексации.

## Обзор

Пайплайн загружает текстовые документы, разбивает их на чанки двумя стратегиями,
генерирует эмбеддинги локальной моделью и сохраняет индекс в FAISS + SQLite.

## Стратегии чанкинга

Доступны две стратегии: fixed_size и structural. Их можно сравнить командой `/index compare`.

### fixed_size

Режет текст на фрагменты фиксированного размера с перекрытием по границам предложений.

### structural

Режет по структуре: заголовки Markdown, функции и классы Python, абзацы текста.

## Установка

Выполните следующие команды для установки зависимостей.

```bash
pip install sentence-transformers einops
```

При первом запуске модель `nomic-ai/nomic-embed-text-v2-moe` скачается автоматически.
